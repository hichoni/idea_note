# 반짝! 아이디어노트 (Idea Note)

초등학생을 위한 발명·아이디어 성장 앱 프로토타입.
떠오른 생각을 자유롭게 기록하고, AI와 함께 발전시키며, 전시관에서 공유하는 경험을 제공합니다.

> **생각 → 아이디어 → 발전 → 발명**

## 미리보기
- `index.html` 을 브라우저로 열면 바로 동작합니다. (단일 파일, 3D 아이콘 내장)
- 반응형: 모바일 세로 = 하단 탭 단일 컬럼 / PC = 좌측 사이드바 + 다단 그리드

## 주요 화면
- 🏠 홈 — 오늘의 질문, 자유 기록, 이번 주 성장 현황
- 📒 노트 — 진행상태(아이디어/성장중/완성)와 진행바
- 🤖 AI 도우미 — 질문 유형으로 아이디어 키우기, URL 요약(데모)
- 🏆 전시관 — 카드형 갤러리, 좋아요·댓글
- 👤 마이페이지 — 레벨·연속기록·뱃지
